# b1-modulo-1-emozioni-reazioni

面向成人 B1 学员的意大利语网页复习练习，共 25 题：

- Parte 1：Parole ed espressioni（8 题）
- Parte 2：Che tono ha?（7 题）
- Parte 3：Come reagisci?（10 题）

## 本地预览

在本文件夹启动任意静态文件服务器即可。项目不依赖框架、构建工具、账号或数据库。

## 发布到 GitHub Pages

1. 新建一个独立仓库，建议命名为 `b1-modulo-1-emozioni-reazioni`。
2. 只需上传 `index.html`、`styles.css`、`app.js` 和 `.nojekyll`。
3. 在仓库 Settings → Pages 中选择从 `main` 分支根目录发布。

这是一套独立静态文件，不会影响或覆盖其他网站。
